# 基洛夫飞艇返工版

127 个方块（含隐藏特效），4 组动画，1024 × 1024 内嵌贴图。

长椭球气囊、三道束带、四个外置螺旋桨与四片尾翼；鲨齿和镰锤使用独立贴图。投弹由腹部舱门下落，燃烧器提升推进转速。
总计127个方块，包含隐藏特效；统一上限300。轮毂、线圈和端口细节以贴图表达。
以Wiki实机外形为主，概念图仅补足遮挡结构；动画时长为模型演示调整值。逐面独立UV，PNG内嵌。

## 使用

- 打开 `基洛夫飞艇.bbmodel`；纹理已内嵌，无需重新指定路径。
- `基洛夫飞艇_贴图.png` 为独立纹理；`基洛夫飞艇_UV.png` 显示逐面 UV 分区。
- `基洛夫飞艇_动作预览.gif` 展示部分代表动作；`基洛夫飞艇_动作关键帧.jpg` 涵盖全部动画。
- 在 Blockbench 动画面板选择需要的动作。切换互斥形态时关闭前一动画，避免多个状态同时叠加。
- 行走和行驶多为原地机构循环；场景位移、伤害、建造逻辑与目标单位由使用方控制。

## 动画组

- 缓慢巡航：4 秒，循环。
- 连续投弹：2 秒，循环。
- 喷射燃烧器：2 秒，循环。
- 恢复螺旋桨推进：1.5 秒，单次。
