# 红警 3 盟军模型资产

按建筑、载具、飞机、海军、步兵分类，保留原有单位、版本及历史模型目录。
`.bbmodel` 包含模型、骨架、贴图和动画；模型实际使用的贴图另存为同目录图片。已有的 `.geo.json` 与 `.animation.json` 导出文件一并保留。
各单位页面列出当前版本入口。网格项目以 Blockbench 文件为准；具体 Minecraft / GeckoLib 运行兼容需在模组接入时确认。
本目录不包含生成提示词、参考图、制作脚本、过程截图或检查报告。许可见仓库根目录。
